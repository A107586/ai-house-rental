## 押金什么时候退？怎么退？
id: faq-deposit-refund
category: 押金
alias: 保证金什么时候退 / 押金退款流程 / 押金能退吗 / 押金多久到账

租期届满且无违约情形的，平台在租客腾房并结清费用后 **7 个工作日内原路退还押金**。
退租时房东会同你一起确认房屋状态，无争议的直接发起退款，
退款按原支付路径返回，到账时间受支付渠道影响可能再多一到两天。
若房屋存在人为损坏，由双方确认扣款金额后退还剩余部分。

## 押金一般收多少？
id: faq-deposit-amount
category: 押金
alias: 押几付几 / 押一付三是什么意思 / 押金收几个月

押金金额由房东在发布房源时设定，最常见的是**押一付三**（押金一个月租金、租金三个月一付）。
具体金额以房源详情页和租赁合同上写明的为准，签约前可以在合同预览里看到。
平台不额外收取中介费或服务费。

## 什么情况下会扣押金？
id: faq-deposit-deduct
category: 押金
alias: 押金被扣 / 扣押金的情形 / 押金扣多少

只有**人为损坏、拖欠费用、违约提前解约**这三类情形才会扣押金。
正常使用产生的自然损耗（墙面轻微污渍、五金件老化等）不属于扣款范围。
扣款金额需要双方在退租确认环节达成一致，房东不能单方面决定。

## 押金扣款我不认可怎么办？
id: faq-deposit-dispute
category: 押金
alias: 押金争议 / 不同意扣押金 / 押金纠纷找谁

先在退租确认环节拒绝确认，然后通过客服转人工申诉，平台会介入核对。
申诉时请准备入住时的房屋照片、聊天记录和维修单据。
双方仍无法达成一致的，按租赁合同约定的争议解决条款处理。

## 押金交了有凭证吗？在哪看？
id: faq-deposit-receipt
category: 押金
alias: 押金凭证 / 押金记录在哪 / 押金交没交怎么查

有，押金作为一条独立账单记录在「我的租约 → 账单」里，缴费成功后会生成缴费流水。
每一笔流水都有交易号、金额、支付方式和时间，可以随时查看。

## 提前退租押金还退吗？
id: faq-deposit-early-checkout
category: 押金
alias: 提前搬走押金 / 没到期退租押金退不退

退，但需要先结清违约金。提前解除合同的一方要支付相当于一个月租金的违约金，
违约金可以从押金里直接抵扣，抵扣后有剩余的按正常流程退还。

## 押金超过 7 个工作日还没到账怎么办？
id: faq-deposit-overdue
category: 押金
alias: 押金迟迟不退 / 押金没收到 / 押金拖着不给

先在「我的租约」确认退租状态是否已完成，未完成说明流程还卡在确认环节。
状态已完成但超过 7 个工作日仍未到账的，通过客服转人工，平台会核查支付流水并催办。

## 水电费怎么算、怎么交？
id: faq-utility-pay
category: 费用
alias: 水费电费怎么交 / 水电费谁交 / 水电费包含在房租里吗

水电费由租客**按实际用量自行向供水供电单位缴纳，不通过平台代收**。
房租里不包含水电费。抄表和缴费方式以当地供水供电单位的规定为准，
平台不参与也不加价。

## 合租的水电费怎么分摊？
id: faq-utility-share
category: 费用
alias: 合租水电 / 水电均摊 / 室友分摊费用

合租房源的水电费由同住租客**按人数均摊**，具体分摊方式以租赁合同约定为准。
如果合同里另有约定（比如按房间面积或独立分表），以合同约定优先。

## 物业费谁交？
id: faq-property-fee
category: 费用
alias: 物业管理费 / 物业费包含吗 / 物业费房东交还是租客交

物业费默认由房东承担，除非租赁合同里另有约定。
签约前可以在合同条款里确认这一项，AI 合同审阅也会把费用承担方作为关键条款抽取出来。

## 取暖费谁承担？
id: faq-utility-heating
category: 费用
alias: 暖气费 / 供暖费谁出 / 冬天取暖费

取暖费的承担方以租赁合同约定为准，平台不做统一规定。
北方房源多数约定由房东承担，签约前请在合同里确认清楚，不要口头约定。

## 宽带、有线电视的费用怎么算？
id: faq-utility-network
category: 费用
alias: 网费 / 宽带谁装 / 有线电视费

宽带和有线电视属于租客自行办理的增值服务，费用由租客承担。
房源详情页标注「已装宽带」的，说明房内有现成线路，但月费仍由使用人自己缴纳。

## 入住时水电表读数要核对吗？
id: faq-utility-meter
category: 费用
alias: 水表电表 / 抄表 / 入住读数

要，**入住当天务必和房东一起抄录水表、电表读数并拍照留存**。
这是划分入住前后费用责任的唯一依据，退租时也按同样方式核对。

## 上一任租客欠的水电费要我交吗？
id: faq-utility-arrears
category: 费用
alias: 历史欠费 / 前租客欠费 / 接手欠费

不需要。入住前的欠费由房东与上一任租客结清，与新租客无关。
如果发现存在历史欠费，请立即通过客服转人工反馈，不要先行垫付。

## 怎么预约看房？
id: faq-viewing-book
category: 看房
alias: 约看房 / 怎么看房 / 预约流程 / 想去看房子

在房源详情页点「预约看房」，或者直接对智能助手说一句
「这周六下午两点想去看」，系统会解析时间并提交预约。
提交后等待房东确认，确认结果通过站内消息通知。

## 可以预约什么时间段看房？
id: faq-viewing-time
category: 看房
alias: 看房时间 / 几点能看房 / 周末能看吗 / 晚上能看房吗

平台可预约时段为**每天 9:00 至 18:00，每次看房占用一小时**。
超出这个范围的时间无法提交，已被其他人占用的时段也会被自动排除并推荐相邻可用时段。

## 预约提交后多久有结果？
id: faq-viewing-confirm
category: 看房
alias: 预约审核 / 房东多久确认 / 预约状态

预约提交后状态为「待审核」，由房东确认。
确认或拒绝的结果都会通过站内消息通知你，可以在「我的预约」里查看当前状态。

## 怎么取消或改约看房？
id: faq-viewing-cancel
category: 看房
alias: 取消预约 / 改时间 / 看房改期 / 不想去了

在约定时间前到「我的预约」里自行取消即可，取消后该时段会重新释放给其他人。
需要改期的，取消后重新预约新时段，或者直接对智能助手说「改到周日上午」。

## 爽约不去看房会怎么样？
id: faq-viewing-noshow
category: 看房
alias: 没去看房 / 放房东鸽子 / 爽约

平台不收取违约费用，但爽约记录会保留。
临时去不了请提前取消，把时段让出来——房东确认后一直空等会影响后续预约的通过率。

## 看房收费吗？
id: faq-viewing-fee
category: 看房
alias: 带看费 / 看房要钱吗 / 中介费

不收费。平台不收取看房费、带看费或中介费，任何以看房名义收费的都不是平台行为。
遇到这种情况请立即通过客服转人工举报。

## 看房是谁带看？
id: faq-viewing-agent
category: 看房
alias: 谁带我看房 / 房东本人吗

由房源所属房东本人或其指定的联系人带看，联系方式在预约确认后的站内消息里给出。
看房时请核对对方身份，不要在看房环节支付任何款项。

## 房子坏了怎么报修？
id: faq-repair-submit
category: 报修
alias: 怎么提报修 / 报修入口 / 设施坏了找谁 / 家电坏了

在「我的租约 → 报修」里描述故障即可，也可以直接对智能助手说
「厨房水管漏水了」，系统会自动判断故障类型和紧急程度并派单。
描述里写清楚**位置 + 现象**，比如「主卧空调不制冷」比「空调坏了」派单更准。

## 报修多久能处理？
id: faq-repair-sla
category: 报修
alias: 维修时限 / 报修多久上门 / 修得快吗

按紧急程度分三档：**紧急报修通常 24 小时内响应，一般报修 48 小时内响应，
可延后的报修在 7 个工作日内安排**。
响应指的是联系你并确认上门时间，不是修完的时间。

## 什么算紧急报修？
id: faq-repair-urgent
category: 报修
alias: 紧急工单 / 什么情况算紧急 / 漏水算紧急吗

涉及**漏水、漏电、燃气泄漏**等安全隐患的报修会被标记为紧急并优先派单。
断电、断水、门锁损坏无法进出也按紧急处理。
遇到燃气泄漏请先关闭阀门、开窗通风并撤离，再报修。

## 维修费用谁出？
id: faq-repair-cost
category: 报修
alias: 修理费谁承担 / 维修费用 / 谁付钱修

房屋本身及原有设施的自然损坏由房东承担；租客使用不当造成的损坏由租客承担。
责任划分以租赁合同的维修责任条款为准，AI 合同审阅会把这一条单独抽取出来提示。

## 报修要传照片吗？
id: faq-repair-photo
category: 报修
alias: 报修上传图片 / 拍照 / 要不要发图

不是必填，但强烈建议传。报修表单支持上传照片，
有照片时维修人员能提前判断故障并带对工具，能少跑一趟。

## 怎么查报修进度？
id: faq-repair-progress
category: 报修
alias: 工单进度 / 报修状态 / 修到哪一步了

在「我的租约 → 报修」里查看工单状态，状态变更时会通过站内消息通知。
工单流转为：待受理 → 已派单 → 处理中 → 已完成。

## 我自己找人修了能报销吗？
id: faq-repair-self
category: 报修
alias: 自行维修 / 垫付维修费 / 自己修能不能报

需要事先在平台报修并取得房东同意，才可能报销。
未经同意自行维修的费用，平台无法支持报销主张。
紧急情况下先处理止损，但要保留照片和票据并第一时间报修留痕。

## 想提前退租怎么办？
id: faq-checkout-early
category: 退租
alias: 提前搬走 / 不想租了 / 提前解约 / 中途退租

任一方提前解除合同的，应**提前 30 日书面通知对方，并向对方支付相当于一个月租金的违约金**。
退租后未到期的租金账单将自动作废。
通知可以在「我的租约」里发起退租申请，系统会记录申请时间作为通知时间。

## 到期正常退租的流程是什么？
id: faq-checkout-process
category: 退租
alias: 退房流程 / 怎么退租 / 到期搬走

四步：在「我的租约」发起退租 → 结清所有未付账单 → 与房东共同验房确认房屋状态 →
双方确认后系统发起押金退款。全程在平台上留痕，不需要线下签纸质单据。

## 退租时房子要打扫吗？交房标准是什么？
id: faq-checkout-clean
category: 退租
alias: 交房标准 / 退租打扫 / 要恢复原样吗

要恢复到入住时的状态：搬空个人物品、清理垃圾、保持基本整洁。
自然损耗不需要修复，人为损坏需要修复或协商折价。
入住时拍的房屋照片是验房时最有力的依据，请务必留存。

## 退租后没到期的账单还要交吗？
id: faq-checkout-bill
category: 退租
alias: 剩余账单 / 退租后账单 / 未到期租金

不用。退租生效后，未到期的租金账单会自动作废，不再产生新账单。
但退租生效**之前**已经产生的欠费必须先结清，否则退租流程无法完成。

## 合同到期不续租需要提前说吗？
id: faq-contract-end
category: 退租
alias: 到期不续 / 需要提前通知吗 / 自然到期

需要。到期不续租的，同样建议提前 30 日告知对方，便于房东安排后续出租。
到期后既不续签也不退租、继续居住的，容易产生费用争议，请务必走完退租流程。

## 怎么续租？
id: faq-renew
category: 退租
alias: 续签 / 继续租 / 到期想接着租 / 延长租期

在「我的租约」里点「续租」，选择续租时长并提交，房东确认后生成新的租约。
租金是否调整由双方协商，续租时会重新生成合同并需要双方确认。

## 可以把房子转租给别人吗？
id: faq-sublet
category: 退租
alias: 转租 / 二房东 / 转给朋友租

未经房东书面同意不得转租。
擅自转租属于违约，房东可以据此解除合同并要求承担违约责任。
确实需要提前结束租期的，走正常的提前退租流程。

## 退租时东西没搬完怎么办？
id: faq-checkout-belongings
category: 退租
alias: 遗留物品 / 东西没搬走 / 留下的家具

请在验房前搬空。遗留物品的处理方式以租赁合同约定为准，
未约定的由双方协商，协商不成可通过客服转人工介入。
超期占用房屋期间产生的费用由租客承担。

## 怎么在线签约？
id: faq-contract-sign
category: 合同
alias: 签合同 / 在线签约流程 / 怎么签租约

看房通过后由房东发起签约，你会收到站内消息，
在「我的租约」里查看合同内容并确认，双方都确认后租约生效并生成首期账单。
确认前请务必看完合同正文。

## 合同智能审阅怎么用？
id: faq-contract-review
category: 合同
alias: AI 看合同 / 合同审阅 / 帮我看看合同有没有坑

在「我的租约」里打开合同，点「智能审阅」。
系统会抽取租期、租金、押金、付款方式、违约责任、维修责任划分等关键条款，
并按严重程度列出风险提示。**审阅结论仅供参考，不构成法律意见。**

## 合同在哪里看？能下载吗？
id: faq-contract-copy
category: 合同
alias: 合同在哪 / 查看合同 / 下载合同

在「我的租约」里点开对应租约即可查看合同全文，正文与审阅结论都存在平台上，
随时可以回看。租约结束后合同记录仍然保留，不会删除。

## 电子合同有法律效力吗？
id: faq-contract-legal
category: 合同
alias: 线上合同有效吗 / 电子合同效力 / 不签纸质的行不行

平台的电子租赁合同双方确认后即成立，合同内容、确认时间与操作记录都有留痕。
如需纸质版，可以打印后由双方另行签署，两者内容应保持一致。

## 合同信息填错了能改吗？
id: faq-contract-change
category: 合同
alias: 合同写错了 / 修改合同 / 改租期

双方确认生效前，房东可以撤回并重新发起签约。
已经生效的合同不能直接修改，需要走解约后重签，或者通过补充约定的方式处理。
发现信息有误请在确认前提出，不要先确认再说。

## 房租怎么交？支持哪些方式？
id: faq-bill-pay
category: 缴费
alias: 交房租 / 怎么付钱 / 付款方式 / 在哪交租

在「我的租约 → 账单」里选择待缴账单发起支付即可，支持平台内的模拟支付渠道。
缴费成功后立刻生成缴费流水，房东侧的收租记录同步更新，不需要另外发截图确认。

## 账单什么时候生成？
id: faq-bill-cycle
category: 缴费
alias: 什么时候出账 / 账单周期 / 几号交租

租约生效时生成首期账单，之后按合同约定的付款周期滚动生成。
账单生成和临近到期时都会通过站内消息提醒，可以在消息中心里查看。

## 逾期没交租会怎么样？
id: faq-bill-late
category: 缴费
alias: 晚交房租 / 忘记交租 / 拖欠租金后果

账单会标记为逾期并持续提醒，逾期期间房东有权按合同约定主张违约责任。
逾期未结清会影响退租流程——退租前必须结清所有欠费。
确实有困难的，请先联系房东协商，不要单方面拖着不处理。

## 怎么注册账号？租客和房东有什么区别？
id: faq-account-register
category: 账号
alias: 注册 / 开户 / 房东怎么注册 / 角色区别

注册时选择身份：租客可以找房、预约、签约、缴费、报修；
房东可以发布房源、处理预约、管理租约、收租和处理工单。

## 我的身份证号安全吗？
id: faq-account-privacy
category: 账号
alias: 隐私 / 个人信息安全 / 身份证会泄露吗 / 实名信息

安全。平台**不存储身份证号原文**，只保存不可逆的哈希值与掩码显示（如 `2102**********1234`）。
校验时用哈希比对，页面和接口返回的都是掩码，任何角色都无法从系统里读出完整号码。

立即通过客服转人工举报，并保留聊天记录与截图。

## 房东怎么发布房源？
id: faq-landlord-publish
category: 房东
alias: 发房子 / 上架房源 / 我要出租

在房东工作台点「发布房源」，填写区域、小区、户型、面积、租金等信息并上传照片。
描述写不出来可以用「智能生成描述」，定价拿不准可以看「定价建议」。
提交后进入审核，审核通过才会对外展示。

## 房源审核要多久？审核不通过怎么办？
id: faq-landlord-audit
category: 房东
alias: 房源审核 / 多久能上架 / 审核没过

提交后由管理员审核，审核期间房源不对外展示，匿名用户也查不到。
未通过的会给出原因，按提示修改后可以重新提交。
常见驳回原因是图片与描述不符、含夸大宣传用语、联系方式写进了描述里。

## 定价建议是怎么算出来的？
id: faq-landlord-price
category: 房东
alias: 租金定多少 / 建议价格 / 定价参考

基于平台内同区域、相近户型与面积的在租房源价格分布给出区间建议，
数据来源是平台真实房源，不是模型凭空生成。建议价仅供参考，最终定价由房东自己决定。

## 房东怎么收租？
id: faq-landlord-collect
category: 房东
alias: 收房租 / 租客交没交 / 收租记录

在房东工作台的「收租」里可以看到名下所有租约的账单状态与缴费流水。
租客在平台完成缴费后记录自动同步，不需要手工登记。
线下收取的款项平台无法记录，建议统一走平台缴费。
