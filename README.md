# 基于 AI 智能体的房屋租赁系统

大连理工大学 2026 年秋季学期实习实训课程设计 · 选题三 · 5 人组

在传统房屋租赁管理系统的基础上，引入 **AI 智能体（Agent）** 层，实现自然语言找房、
合同智能审阅、智能客服与报修工单自动分派，打造信息透明、操作简便的在线租赁平台。

---

## 目录结构

```
├── back/            SpringBoot 后端（Java 8 + MyBatis-Plus + Shiro）
├── front/           Vue 2 前端（element-ui）
├── agent/           【待建】AI 智能体服务（Python + FastAPI）
├── db/T040.sql      数据库建库脚本（13 张表）
├── docs/            设计文档、评审材料
│   └── upstream/    上游原项目的说明与功能文档（供参考）
└── LICENSE          MIT
```

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 2.6 · element-ui 2.13 · axios · ECharts |
| 后端 | SpringBoot 2.2.2 · MyBatis-Plus · Shiro · Java 8 |
| 智能体 | Python · FastAPI · 大模型 API（待定） |
| 数据库 | MySQL |

前后端分离，智能体作为独立微服务通过 HTTP 与后端通信。

## 核心业务模块

房屋信息 · 户主管理 · 租客管理 · 看房申请 · 租赁合同 · 收租信息 · 收租统计 · 报修信息 · 维修数据 · 公告管理

## AI 智能体功能（本项目自研部分）

- **自然语言找房** — 「中山区两室一厅，3000 以内，地铁 10 分钟」→ 解析为结构化查询
- **租赁合同智能审阅** — 抽取关键条款，标注对租客不利的条目
- **智能客服** — RAG 检索房源库与常见问答
- **报修工单自动分派** — 从文字描述判断故障类型与紧急程度，路由给对应维修工
- **数据分析报告** — 租金走势与房源情况自动生成报告
