# 基于 AI 智能体的房屋租赁系统

大连理工大学 2026 年秋季学期实习实训课程设计 · 选题三 · 5 人组

在传统房屋租赁管理系统的基础上，引入 **AI 智能体（Agent）** 层，实现自然语言找房、
合同智能审阅、智能客服与报修工单自动分派，打造信息透明、操作简便的在线租赁平台。

---

## 目录结构

```
├── server/          业务后端（Python + FastAPI + SQLAlchemy）      ← 当前主线
├── agent/           AI 智能体服务（Python + FastAPI）              ← 当前主线
├── web/             React 前端（Vite + React 18）
├── docs/            设计文档、评审材料、测试说明
├── start-all.ps1    一键启动两个服务
├── back/ front/     早期 SpringBoot + Vue 方案，暂留作参考
├── db/              早期 MySQL 建库脚本与初始化工具
└── LICENSE          MIT
```

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 · Vite |
| 后端 | Python · FastAPI · SQLAlchemy |
| 智能体 | Python · FastAPI · DeepSeek API |
| 数据库 | 开发用 SQLite，部署用 MySQL |

前后端分离，智能体作为独立微服务通过 HTTP 与业务后端通信。

## 快速开始

```
pip install -r server/requirements.txt
cd web && npm install && npm run build
cd server && python seed.py
powershell -ExecutionPolicy Bypass -File .\start-all.ps1
```

打开 **<http://localhost:8080>** 就是完整网站——业务后端直接托管前端构建产物，
不需要单独启动前端服务。

| 地址 | 说明 |
|---|---|
| **<http://localhost:8080>** | **网站** |
| <http://localhost:8080/docs> | 业务后端接口文档 |
| <http://localhost:8000/docs> | 智能体接口文档 |

演示账号：`tenant1` / `test123`（租客）· `landlord1` / `test123`（房东）· `admin` / `admin123`

改前端代码时用开发模式：`cd web && npm run dev`，访问 <http://localhost:5173>，有热更新。

**怎么测试见 [docs/测试说明.md](docs/测试说明.md)**，含 153 条手工用例。

## 开发中修复的越权问题

这些是写代码与写测试时发现的，不是规划出来的：

| 问题 | 影响 |
|---|---|
| 匿名可查待审房源 | 房东一发布就被公开看到，审核机制形同虚设 |
| 工单状态无归属校验 | 任何房东能改别人房源的工单 |
| 工单列表无鉴权 | 匿名可拉全平台工单，含联系人与故障描述 |
| 预约表的唯一约束 | 取消的预约永久占住时段 |
| 管理员可禁用自己 | 一键锁死整个后台 |

每条都有对应的回归测试。
