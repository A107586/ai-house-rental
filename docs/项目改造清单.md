# 基于 AI 智能体的房屋租赁系统改造清单

## 1. 项目改造总目标

当前 GitHub 项目是一个基于 LangGraph 的多智能体 AI 房产助手，主要功能包括自然语言找房、房源推荐、看房预约和房源卡片展示。它具备 AI 智能体特色，但还不是一个完整的在线房屋租赁平台。

为了满足实训项目“基于 AI 智能体的房屋租赁系统”的要求，建议将现有项目改造成以下完整架构：

```text
React 前端网站
    ↓ Ajax / Axios 异步请求
FastAPI 后端接口服务
    ↓ 数据库查询与业务处理
PostgreSQL / Supabase 数据库
    ↓ AI 需求理解、推荐、预约辅助
LangGraph 多智能体服务
```

最终系统应具备：

- 用户注册登录
- 房源浏览与筛选
- 房源详情查看
- 收藏房源
- 预约看房
- 房东发布和管理房源
- 管理员审核房源
- AI 自然语言找房
- AI 智能推荐
- AI 预约辅助
- 数据库增删改查
- 前后端 Ajax 异步通信

## 3. 当前项目缺少的内容

### 3.1 缺少完整 React 前端网站

当前项目没有完整页面，例如：

- 首页
- 登录页
- 注册页
- 房源列表页
- 房源详情页
- 个人中心
- 房东中心
- 管理员后台

因此需要新增 `web/` 目录，用于开发完整 React 前端。

### 3.2 缺少后端 REST API

当前项目主要通过 LangGraph 运行智能体，没有完整的后端业务接口。

需要新增 FastAPI 后端接口，例如：

- 用户注册登录接口
- 房源增删改查接口
- 收藏接口
- 预约接口
- 管理员审核接口
- AI 找房接口

### 3.3 缺少数据库建表文件

当前代码依赖 Supabase 的 `properties` 表和 `search_properties_rpc` 函数，但仓库中没有对应的 SQL 文件。

需要新增：

```text
database/schema.sql
database/seed.sql
database/rpc.sql
```

### 3.4 缺少国内租房业务字段

当前项目字段偏国外房产场景。

需要增加国内租赁常见字段：

- 押金
- 整租/合租
- 小区
- 区域
- 楼层
- 朝向
- 付款方式
- 近地铁
- 家电设施
- 房源审核状态

### 3.5 缺少管理端功能

完整系统应包含管理员后台，用于：

- 管理用户
- 审核房源
- 查看预约
- 查看统计数据

## 6. 数据库表设计

建议使用 PostgreSQL / Supabase。以下 SQL 可以保存到：

```text
database/schema.sql
```

### 6.1 用户表 users

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    phone VARCHAR(20),
    email VARCHAR(100),
    role VARCHAR(20) NOT NULL DEFAULT 'tenant',
    avatar_url TEXT,
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

字段说明：

- `role`：用户角色，可选值为 `tenant`、`landlord`、`admin`
- `status`：用户状态，可选值为 `active`、`disabled`
- `password_hash`：加密后的密码，不能保存明文密码

---

### 6.2 房源表 houses

```sql
CREATE TABLE houses (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    landlord_id UUID REFERENCES users(id),
    title VARCHAR(100) NOT NULL,
    description TEXT,
    city VARCHAR(50) NOT NULL,
    district VARCHAR(50),
    community VARCHAR(100),
    address TEXT,
    rent_price NUMERIC(10, 2) NOT NULL,
    deposit NUMERIC(10, 2),
    payment_method VARCHAR(50),
    bedrooms INT,
    living_rooms INT,
    bathrooms INT,
    area_sqm NUMERIC(8, 2),
    floor VARCHAR(50),
    orientation VARCHAR(50),
    rental_type VARCHAR(20),
    house_type VARCHAR(50),
    status VARCHAR(20) DEFAULT 'pending',
    latitude NUMERIC(10, 6),
    longitude NUMERIC(10, 6),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

字段说明：

- `landlord_id`：发布房源的房东 ID
- `community`：小区名称
- `rent_price`：月租金
- `deposit`：押金
- `payment_method`：付款方式，例如押一付一、押一付三
- `rental_type`：租赁方式，例如 `whole` 整租、`shared` 合租
- `house_type`：房源类型，例如普通住宅、公寓、别墅
- `status`：房源状态，例如 `pending`、`approved`、`rejected`、`offline`

---

### 6.6 收藏表 favorites

```sql
CREATE TABLE favorites (
```

```sql
CREATE TABLE appointments (
```

作用：

### 6.9 AI 对话记录表 chat_messages

```sql
CREATE TABLE chat_messages (
```

字段说明：

- `role`：消息角色，可选 `user` 或 `assistant`

### 6.10 评论评价表 reviews

```sql
CREATE TABLE reviews (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id),
    house_id UUID REFERENCES houses(id),
    rating INT CHECK (rating >= 1 AND rating <= 5),

    created_at TIMESTAMP DEFAULT NOW()
);
```

作用：

- 用户对房源进行评分和评价
- 可作为拓展功能，如果时间不足可以不做

