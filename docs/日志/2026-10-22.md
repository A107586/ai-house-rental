### 缴费与押金 · @A107586（`093ccb5`）

- **收银台过期后，这张账单再也付不了。** 复现：发起支付 → 把支付单改成已过期 → 再发起，
  回 `409 该账单正在支付或已经支付，请勿重复提交`；线下代收也一样。
  根因：`payments.bill_id` 是唯一的，关单只改了状态，重新发起时又插一条，撞唯一约束。
  `start_payment` 里的注释写着「不关的话它会一直占着 bill_id 的唯一约束」——**作者以为关单就让出了约束，其实没有**。
  修法：一张账单一条支付记录，记最近一次尝试；关掉的、失败的就地换成新的一单（新 trade_no），
  旧单迟到的回调查不到它、不会误入账。**不动表结构**——黑盒测试周不做迁移。
  被否决的方案：去掉唯一约束、允许多条支付记录。更「对」，但要迁移、要改 `bill.payment` 的所有用法。
- **退租后没交的押金挂在「待缴」里。** 页面提示「这笔欠款请与房东线下结清」，而退租结算写的是
  「押金未曾缴纳，无需退款」——让人去线下补交一笔租约已结束的押金。押金是担保，不是欠款，现在退租时一并作废。
  **已到期未缴的租金照旧保留**：那是住过的月份，是真欠款。
- 助手「帮我交房租」不看 `payable`：旧租约的欠款到期最早、后端拒收，却排在第一位。现在只挑能付的；
  只剩这种欠款时如实说「要线下结清」，不再说「都结清了」。

### 预约与合同正文 · @A107586（`ee0fbe8`）

- **看房预约任意状态都能改成任意状态。** 复现：租客取消 → 别人约同一时段并被确认 → 房东把取消的那条「确认」回来，
  同一时段两条已确认。现在只能往前走：待确认 → 确认 / 拒绝 / 取消，已确认 → 取消，拒绝与取消是终点；
  时间已过的不能再确认；重复点同一个状态不重复发通知。前端按钮本来就只在合规的状态出现，没有流程被挡住。
- **租客取消看房，房东和中介收不到任何通知**（实测 0 条）——代码里「不通知取消的人自己」是对的，
  但漏了通知另一方。补上。「我的预约」里已确认的看房原先没有取消按钮（只能爽约），现在有，带二次确认。
- 房子签约生效后，别人还没到时间的看房预约原先一直「待确认」；现在自动取消并告诉约的人。
- 合同正文写「每期首月 5 日前支付当期租金」，账单却按起租日到期、逾期也按它算——
  20 日起租，正文说 5 日前交，系统 21 日才算逾期。正文改为写出真正的缴费日。

## 四、踩的坑

**`git diff --name-only` 列不出「只差换行」的文件。**（验证手段本身出错）
重新出图后 26 个图文件显示已修改，其实只有 3 个内容变了。按 `git diff --name-only` 去还原，列表是空的——
autocrlf 归一化之后 diff 认为没差别，`git status` 却按时间戳报改动。改用 `git status --porcelain` 的列表，
再逐个 `git diff --quiet --ignore-cr-at-eol` 判断。另：中文路径默认被转义成 `\345\233\276`，要 `-c core.quotepath=off`。

**注释描述了一个不存在的状态。**（文档与实现不一致）
支付那处 bug，代码注释写的是正确的意图（「关掉才不会占着唯一约束」），实现却没做到。
和 9-28 部署单元里那句「刻意不加 `--proxy-headers`」是同一类：**读注释会以为没问题，只有跑一遍才知道。**

## 五、需要拍板的（没有改）

这几处改起来跨前后端和智能体，或者本身是产品规则，在黑盒测试周里不擅自动：

1. **任何人都能给任何房源报修，包括没登录的。** 房源详情页的「报修」对所有人开放，`/agent/repair` 提交时不带用户身份，
   后端 `POST /api/repairs` 也不校验是不是这套房的租客；而房源的维修历史是公开的——等于谁都能往别人的房源页上写
   「漏水严重」。建议：只有该房源生效中租约的租客、房东 / 受托中介、管理员能报修；智能体把用户令牌转给后端；
   详情页只对在住租客显示「报修」。测试成绩书 #33 测的是分派结果，不受影响，但要用在住租客的账号做。
2. **房东点「退租」立即生效，不需要租客确认，可扣满押金。** 而系统自己生成的合同第六条写的是「提前 30 日书面通知，
   并支付一个月租金的违约金」。建议房东发起的提前退租也走「一方申请、另一方确认」，或至少限制在到期后 / 租客已申请时。
3. **提前退租时，已付未住的租金不退。** 只作废了未付的账单；押一付三的合同，系统生成的条款写着
   「甲方应退还已付但尚未居住月份的租金」。需要定规则：按天还是按月折算、是否先抵违约金。
4. **「保存搜索」从界面上找不到了。** 9-10 有意改成自动搜索记录、删了「我的搜索」页签，但后端接口、`SavedSearchPanel`、
   README 的 K-09「已完成」、测试成绩书里的用例都还在。要么恢复入口，要么把剩下的删干净、文档改口。
5. **租约过了到期日不会自动结束。** 状态一直「生效中，剩余 0 天」，房源一直「已出租」，要房东手动退租。
   建议到期后显示「已到期，待办理退租」并在房东工作台提醒。演示库目前没有这种合同。
