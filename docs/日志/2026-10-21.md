### 上午 · 双击一键启动，后端和智能体起不来 · @A107586

- **现象**：面板上业务后端、智能体一直「启动中」。两份日志都停在：

  ```
  INFO:     Uvicorn running on http://0.0.0.0:8080 (Press CTRL+C to quit)
  INFO:     Started reloader process [4572] using StatReload
  ```

  没有 "Application startup complete"，netstat 里 8080、8000 都没在监听，
  而 reloader 进程还活着。
- **根因**：`start-everything.bat` 用 `pythonw` 起面板（为了没有黑窗口），面板原先拿
  `sys.executable` 起子进程——于是后端、智能体也跑在 pythonw 下。`uvicorn --reload`
  的真正服务是 multiprocessing 拉起的孙进程，**pythonw 下它没有 stdout/stderr**，
  uvicorn 配日志时一碰 `sys.stdout` 就抛异常，而异常本身也无处可写。
- **为什么之前没发现**：我之前验证面板用的是 `.claude/launch.json`，那里写的是
  `python launcher/panel.py`——python.exe 下一切正常。**验证走的路径和用户走的不是同一条。**
- **修法**：`find_python()` 遇到 pythonw.exe 换成同目录的 python.exe。黑窗口本来就由
  `CREATE_NO_WINDOW` 负责藏，用不着 pythonw。没有改成去掉 `--reload`：那会掩盖问题而不是修掉它，
  开发时热重载也还要用。
- 另加「没响应」状态：进程活着、端口超过启动时限还不应答，就不再显示「启动中」，
  而是红色「没响应」并提示看日志——这次「看起来在启动」看了好几分钟。
- **验证**：照 bat 的方式用 pythonw 起面板，后端 /docs 200、智能体 /health 200，
  子进程是 python.exe。

### 中午 · 面板加「配置」 · @A107586

- **大模型**：远程 API / 本地模型 / 不用模型三选一。远程可填地址、Key，「取列表」从服务商的
  `/v1/models` 拉当前提供的模型，「测试连接」发一句最短的对话并计时。保存写 `agent/.env`、
  重启智能体（`load_dotenv` 不覆盖已有环境变量，只能整进程重启）。
  模式的判法照抄 `config.py` 的 `llm_enabled`（provider 和 Key 都非空），
  否则面板说的和智能体做的不是一回事。切到本地或纯规则之前，远程的地址和模型名记在
  `launcher/panel-settings.json`（不含 Key，不进 git），切回来原样填回。
- **高德**：Web 端 Key、安全密钥写 `web/.env.local`，Web 服务 Key 写 `server/.env`；
  留空的项不动。Web 端两项是构建时写进前端的，所以保存后重启 5173、并在后台
  `npm run build`（8080 托管的是 dist），面板上显示构建进度，日志里多一个「网站构建」。
- **改 .env 的方式**：只替换那几行，注释和别的配置原样保留；同名多行全部替换（dotenv 里后一行算数，
  只换第一行会被后一行盖回去）；保留 BOM 和原换行风格；先写临时文件再 `os.replace`。
  **值里不许有空白、引号、#、换行**——一个换行就能在 `.env` 里凭空多出一行
  `LLM_BASE_URL=…`。
- **只认面板自己的网页**。能改 Key 和地址之后，这一条就不能省了：任何网页都能往
  127.0.0.1:8099 发一个 `text/plain` 的「简单请求」（不触发 CORS 预检），把
  `LLM_BASE_URL` 改到别人的服务器，智能体下一次调用就把 Key 送过去了。
  现在 Host 必须是 127.0.0.1/localhost 加本端口（挡 DNS 重绑定），POST 必须是
  `application/json`（跨站要先预检，而面板不应答 OPTIONS），带了 Origin 就必须是面板自己。
  实测 `curl -H "Content-Type: text/plain"` → 403。
- **Key 只进不出**：配置接口只回「有没有」；换了服务地址而 Key 留空时拒绝沿用旧 Key——
  否则就是把这一家的 Key 发给了另一家。服务商的报错里如果回显了 Key，也先替换成 `***`。
- **被测试抓到的一个 bug**：切到本地模型再切回远程、Key 留空，面板说「换了服务地址」不让保存——
  比的是 `.env` 里的当前地址，而那时它是本机地址。改成：当前是本机地址时，
  比切走前记下的远程地址。

### 下午 · 实测助手，超时 7 秒基本不可用 · @A107586

配好之后对着跑起来的智能体问了 8 句（未登录，`/agent/chat`）。前两句还正常，第三句起全部秒回「连不上大模型」：

```
 27.6s  押金怎么退            answered
  8.2s  中山区两室一厅三千以内   unavailable
  8.2s  退租要提前多久         unavailable
```

**超时不重试、助手不退回规则**，连续两次超时还会熔断 60 秒，于是后面每句都瞬间失败。
仓库里的 `.env.example` 写的是 30，只有本机这份被调紧了。
